AgroVerde: Mercado de Carbono & Descarbonização

Concurso Agrinho 2026 Categoria: Programação Subcategoria 3 (Front-End)

Tema

Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente

Objetivo

Este projeto explora como o agronegócio brasileiro é protagonista na geração de créditos de carbono e na descarbonização da economia. O site apresenta de forma educativa e interativa os conceitos do Mercado de Carbono, o papel do produtor rural, e o avanço legislativo do Brasil nessa área.

Tecnologias utilizadas

- HTML5: estrutura semântica com tags como `section`, `article`, `header`, `footer`, `nav`, `label`, `input`, `button`
- CSS3: variáveis CSS, Flexbox, Grid, Media Queries para responsividade, transições e animações
- JavaScript (ES5/ES6): manipulação do DOM, eventos, IntersectionObserver, cálculos dinâmicos

Funcionalidades

- Contador animado no hero com números que crescem ao carregar a seção
- Menu responsivo com toggle para dispositivos móveis
- Diagrama interativo do fluxo do mercado de carbono
- Abas comparativas entre Mercado Regulado e Voluntário
- Timeline da trajetória do Brasil no mercado de carbono
- Calculadora de créditos de carbono** — simula toneladas de CO₂e e valor estimado
- Quiz educativo com 5 perguntas sobre o tema
- Scroll reveal com IntersectionObserver para animação suave de elementos
